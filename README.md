**Expense Tracker** is a lightweight yet powerful single-page web application designed to help individuals and families manage their daily expenses efficiently. Built entirely with vanilla JavaScript and modern web technologies, it provides a seamless experience for tracking spending, analyzing monthly trends, and comparing expenses across family members — all without requiring a backend server.

> 💡 **Why this project?** Managing money is hard. This app solves the problem of scattered expense tracking by providing a clean, intuitive interface with instant visual feedback.

---

## ✨ Features

### 🏠 Home Dashboard
- 📊 **Real-time Summary Cards** — View current month's expense, total transactions, and top spending category at a glance
- ➕ **Quick Add Expense** — Log expenses with date, family member, category, description, and amount
- 📋 **Transaction History** — Sortable list with one-click delete functionality
- 🍩 **Category-wise Pie Chart** — Interactive doughnut chart powered by Chart.js

### 📅 Monthly Totals
- 📈 **Month-wise Breakdown** — See total spending for each month in descending order
- 🧮 **Accurate Calculations** — Timezone-safe date parsing for reliable monthly aggregation

### 👨‍👩‍👧 Family Expenses
- 👥 **Multi-user Tracking** — Track expenses for Me, Spouse, Child, and Other family members
- 📊 **Comparative Analysis** — Side-by-side monthly comparison across all family members
- 🏷️ **Dynamic Headers** — Automatically adapts to the family members in your data

### 🎨 UI/UX Highlights
- 📱 **Fully Responsive** — Looks great on desktop, tablet, and mobile
- 💾 **Persistent Storage** — Data saved in browser's LocalStorage (no data loss on refresh)
- 🎭 **Premium Design** — Gradient backgrounds, smooth animations, and modern card layouts
- 🚪 **Logout Feature** — Clear data and reset the app with a single click
